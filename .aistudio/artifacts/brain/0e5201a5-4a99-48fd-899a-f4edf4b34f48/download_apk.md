# Tải File Cài Đặt Fix Lag Turbo (APK)

File APK cài đặt đã được đóng gói sẵn sàng:
- **Tên ứng dụng:** Fix Lag Turbo
- **File APK:** `FixLagTurbo.apk`
- **Phiên bản:** 1.0 (Debug)

### Cách tải trên điện thoại của bạn:
1. Nhấn vào nút dấu ba chấm **`...`** ở góc dưới cùng bên phải màn hình (ngay cạnh tab **Artifacts**).
2. Chọn **Export** hoặc **Download Project / Download APK**.
3. Cài đặt file APK vừa tải về trên điện thoại Android của bạn.
