# Hướng dẫn tải app Remix Fix Lag Turbo về điện thoại

File cài đặt APK đã được tạo thành công và sẵn sàng để bạn cài đặt lên điện thoại Android!

---

### Cách 1: Tải trực tiếp file APK từ AI Studio (Nhanh nhất)
1. Nhìn sang cột hoặc thanh công cụ bên phải (hoặc góc trên/dưới giao diện AI Studio).
2. Mở tab **Artifacts** (hoặc nhấn vào danh sách file Artifact).
3. Nhấn vào file **`RemixFixLagTurbo.apk`** để tải trực tiếp về điện thoại hoặc máy tính.
4. Mở file APK trên điện thoại Android và chọn **Cài đặt** (Install). *(Nếu máy hỏi cho phép cài đặt ứng dụng từ nguồn này, chọn "Cho phép / Allow")*.

---

### Cách 2: Tải qua menu Export / Settings
1. Nhấn vào nút menu ba chấm **`...`** (hoặc biểu tượng **Settings** / **Export** ở góc trên/góc giao diện).
2. Chọn **Download Project** hoặc **Export APK / ZIP**.
3. Nếu tải ZIP dự án về máy tính, bạn chỉ cần mở thư mục `app/build/outputs/apk/debug/app-debug.apk` để lấy file cài đặt.
